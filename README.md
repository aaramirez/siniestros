# Siniestros

El momento de la verdad de una aseguradora, de punta a punta: el aviso, la apertura y la cobertura, el ajuste y el peritaje, las reservas, los pagos, los talleres y las clínicas, el recobro, el fraude, la automatización con imágenes y reglas, y los indicadores que dicen si el área funciona.

**Ver en línea:** https://aaramirez.github.io/siniestros/
